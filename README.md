# 🎒 Школьный Telegram-бот для 5–11 классов (Webhook + Railway + PostgreSQL)

Полноценный асинхронный Telegram-бот на **aiogram 3**, **FastAPI**, **SQLAlchemy 2.0 (async)** и **PostgreSQL**, созданный для объединения учеников одного класса и школы, а также ежедневного справедливого распределения роли дежурного администратора класса.

Бот работает исключительно через **Telegram Webhook** и полностью сконфигурирован для быстрого деплоя на платформу **Railway**.

## ✨ Функционал

- **Строгая сегментация по школам и классам**: «Школа №1, 8-А» и «Школа №2, 8-А» изолированы друг от друга.
- **Поддержка только 5–11 классов** (младшие классы 1–4 не допускаются валидатором).
- **Справедливое назначение дежурного администратора**: алгоритм учитывает число предыдущих назначений и давность выбора, исключая повторные назначения одних и тех же учеников.
- **Автоматический планировщик (APScheduler)**: ротация администраторов запускается ежедневно в 07:00 утра с учетом часового пояса (`TIMEZONE`, по умолчанию `Asia/Tashkent`).
- **Модерация рассылки**: перед отправкой ДЗ, расписания или объявления администратор подтверждает отправку кнопками «✅ Отправить» / «❌ Отмена».
- **Защита от сбоев**: обработка блокировок бота пользователями, защита от флуд-контроля Telegram API (rate-limiting) и транзакционность БД.
- **Эндпоинт здоровья**: `GET /health` для проверки доступности сервиса Railway.

## 1. Как создать Telegram-бота через BotFather

1. Откройте Telegram и найдите официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду:
   ```text
   /newbot
   ```
3. Введите читаемое имя для вашего бота (например: `Школьный Класс Бот`).
4. Введите юзернейм бота, который должен оканчиваться на `bot` (например: `my_school_class_admin_bot`).
5. BotFather пришлет сообщение с токеном вида:
   ```text
   7123456789:AAFlm3k_QxZ123456789abcdefghijk
   ```
6. Сохраните этот токен — это значение переменной `BOT_TOKEN`.

## 2. Развертывание проекта на Railway

1. Зарегистрируйтесь или авторизуйтесь на сайте [railway.app](https://railway.app).
2. Создайте новый проект, нажав **«New Project»**.
3. Выберите способ загрузки кода:
   - **Deploy from GitHub repo**: создайте репозиторий со всеми файлами данного проекта и выберите его.
   - Или через **Railway CLI**:
     ```bash
     npm i -g @railway/cli
     railway login
     railway link
     railway up
     ```
4. В настройках сервиса в Railway (Service Settings) перейдите во вкладку **Networking** и нажмите **Generate Domain** (например, сгенерируется `school-bot-production.up.railway.app`). Скопируйте получившийся URL с протоколом `https://`.

## 3. Подключение базы данных PostgreSQL

1. В вашем проекте Railway нажмите **«+ New»** ➔ **«Database»** ➔ **«Add PostgreSQL»**.
2. Railway автоматически создаст базу данных PostgreSQL.
3. Перейдите в настройки сервиса с ботом:
   - Во вкладке **Variables** нажмите **Add Reference** или добавьте переменную:
     ```env
     DATABASE_URL = ${{Postgres.DATABASE_URL}}
     ```
   *(Приложение автоматически преобразует схему `postgres://` или `postgresql://` в асинхронный драйвер `postgresql+asyncpg://`)*.
4. При старте бота все таблицы (`users`, `admin_history`, `school_messages`) и индексы создаются автоматически!

## 4. Настройка переменных окружения

В разделе **Variables** сервиса бота укажите следующие переменные:

| Переменная | Описание | Пример значения |
| :--- | :--- | :--- |
| `BOT_TOKEN` | Токен бота от @BotFather | `123456789:AA...` |
| `DATABASE_URL` | Ссылка на PostgreSQL (из Railway Postgres) | `postgresql://...` |
| `WEBHOOK_URL` | Публичный HTTPS-домен вашего сервиса | `https://school-bot-production.up.railway.app` |
| `TIMEZONE` | Временная зона для смены администратора | `Asia/Tashkent` (или `Europe/Moscow`) |
| `PORT` | Порт приложения | Предоставляется Railway автоматически |

## 5. Проверка работоспособности

### Проверка Health-check
Откройте в браузере или терминале адрес:
```bash
curl https://school-bot-production.up.railway.app/health
```
Ожидаемый ответ:
```json
{
  "status": "ok",
  "timestamp": "2026-10-28T14:30:00.000000",
  "service": "school-telegram-bot"
}
```

### Проверка статуса Webhook в Telegram API
Замените `<BOT_TOKEN>` на ваш токен и откройте в браузере:
```text
https://api.telegram.org/bot<BOT_TOKEN>/getWebhookInfo
```
В ответе поле `"url"` должно указывать на:
```text
https://school-bot-production.up.railway.app/webhook
```
а поле `"has_custom_certificate"` быть `false`, `"pending_update_count"` близким к `0`.

## 6. Как проверить, что бот работает

1. **Регистрация первого ученика**:
   - Нажмите `/start`.
   - Введите Имя: `Алексей`.
   - Введите Фамилию: `Смирнов`.
   - Введите Школу: `Школа №1`.
   - Выберите класс с помощью кнопок или введите текстом: `8-А`.
   - Так как в этом классе еще нет учеников, бот сразу назначит вас сегодняшним администратором!
2. **Проверка главного меню**:
   - Нажмите кнопку `👤 Мой профиль` — отобразится имя, школа, класс и статус администратора.
   - Нажмите `👑 Администратор дня` — отобразится подтверждение вашей роли.
3. **Регистрация второго ученика**:
   - Попросите друга или зайдите с другого аккаунта Telegram, введите `/start`, укажите ту же школу `Школа №1` и тот же класс `8-А`.
   - Этот пользователь будет зарегистрирован как ученик.
4. **Проверка рассылки**:
   - С первого аккаунта (администратора) отправьте фото тетради или текст «Завтра геометрия на 2 уроке».
   - Выберите категорию (например, `📚 Домашнее задание`).
   - Нажмите `✅ Отправить`.
   - Второй ученик мгновенно получит уведомление с материалом!
5. **Проверка изоляции**:
   - Зарегистрируйте третий аккаунт в `Школа №2`, класс `8-А`.
   - Сообщения из Школы №1 **никогда** не придут в Школу №2.
